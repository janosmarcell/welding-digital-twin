# TRL4 – Laboratory Validation

## Objective
Validation of the core Digital Twin components for robotic welding quality monitoring under laboratory conditions.

## Research components
- Welding process time-series acquisition and analysis
- Processing of 2D weld images
- Processing and registration of 3D point clouds
- Analysis of welding speed groups
- Anomaly identification and data quality assessment
- Evaluation of experimental repeatability

## Experimental data
The research includes welding experiments at five nominal travel speeds: 30, 40, 50, 60 and 70 cm/min.

The dataset contains 150 welding process CSV recordings, complemented by available 2D images and 3D point-cloud measurements.

## Validation status
Existing laboratory research assets are available. Formal validation evidence and acceptance criteria are maintained separately.
