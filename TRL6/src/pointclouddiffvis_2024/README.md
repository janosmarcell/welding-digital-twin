
# PointCloudDiffVis

This program diffs 2 point cloud files.

## Dev Setup

Install https://github.com/Relintai/gdnative_python

Then for x11:

addons/pythonscript/x11-64/bin/python3 -m ensurepip

addons/pythonscript/x11-64/bin/python3 -m pip install open3d matplotlib numpy

For windows (works with wine):

addons/pythonscript/windows-64/python.exe -m ensurepip

addons/pythonscript/windows-64/python.exe -m pip install open3d matplotlib numpy
