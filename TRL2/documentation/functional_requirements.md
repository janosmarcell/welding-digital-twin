| F2-05 | Produce explainable defect-candidate report | Planned interface, not production approval |
| F2-06 | Store software, input and test provenance | Needed for reproducibility |

## Key risks
Incomplete modality coverage; scanner and illumination variation; false positive geometrical clusters; inability to observe internal damage; loss of sample/segment identity; confusion between methodological anomaly thresholds and standards-based acceptance limits.

Current ISO 5817 / ISO 6520-1 editions must be verified before any formal qualification.
